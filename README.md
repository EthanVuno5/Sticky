# Sticky

> A simple sticky note application for creating, organizing, and managing notes.

Sticky is a frontend web application designed to provide a simple and interactive way to create and manage sticky notes.

This project is currently **under development**. The current version focuses on the frontend interface and user interactions. Backend functionality and persistent data storage have not been implemented yet.

## ✨ Features

* Create and manage sticky notes.
* Interactive note interface.
* Simple and clean user interface.
* Responsive design for different screen sizes.
* Dynamic note interactions.
* Lightweight frontend application.
* Drag and organize cards flexibly inside boards for better note organization.
* Multiple boards for separate workflow.
* Dynamic cards organization based on window size

## 🛠️ Tech Stack

* **Vite** — Development environment and build tool.
* **React** — Frontend library for building the user interface.
* **Tailwind CSS** — CSS framework for styling and responsive design.
* **JavaScript / JSX** — Application logic and component development.
* **HTML & CSS** — Core web technologies.

## 🚧 Development Status

This project is currently **in development**.

The current version is a frontend-only application.

### Currently implemented

* Frontend user interface.
* Sticky note interactions.
* Responsive layout.
* Client-side application state.

### Not implemented yet

* Backend.
* Database.
* User authentication.
* Persistent data storage.
* Cloud synchronization.

Currently, notes are **not permanently saved**. Data is handled on the client side and will be lost when the application state is reset or the page is refreshed.

Backend and persistent storage will be added in future development.

## 🚀 Installation

### 1. Install Node.js

Download and install Node.js from:

https://nodejs.org/

npm is included with Node.js, so you don't need to install it separately.

Check that Node.js and npm are installed:

```bash
node --version
npm --version
```

### 2. Clone the repository

```bash
git clone https://github.com/EthanVuno5/Sticky.git
```

### 3. Enter the project folder

```bash
cd Sticky
```

### 4. Install dependencies

```bash
npm install
```

### 5. Start the development server

```bash
npm run build
npm run dev
```

### 6. Open the website

Open the local development URL provided by Vite, usually:

```text
http://localhost:5173/
```

### 7. Stop the server

```text
Ctrl + C
```
